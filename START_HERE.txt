MICRO INVENTORY & INVOICE GENERATOR — FRONTEND DELIVERY

1. Extract the ZIP file.
2. Open the micro_inventory_invoice_generator folder in VS Code.
3. Open a VS Code terminal.
4. Run:

   cd frontend
   npm install
   npm run dev
